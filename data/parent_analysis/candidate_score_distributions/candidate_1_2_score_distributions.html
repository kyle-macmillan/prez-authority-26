How the source corpus becomes the reported n

Source document IDs run as high as 20,232, but IDs are not contiguous. This analysis starts from the 16,397-document development corpus—the main analysis split used to construct and rank parent candidates. The separately reserved holdout split is not used in this ranking. The codebook-based ceremonial filter excludes 5,437 directives, leaving 10,960 directives eligible to appear as children or parents. Automatic reference matching identifies parents for 2,062 children, leaving 8,898 unresolved children for candidate ranking. Candidate 1 exists for 8,894 children and Candidate 2 for 8,890. Each chart's n is the number of those candidate rows with a non-missing score in that channel, so it can be smaller again.
