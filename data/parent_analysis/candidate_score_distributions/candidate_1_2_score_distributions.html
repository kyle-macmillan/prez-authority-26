How the source corpus becomes the reported n

Source document IDs run as high as 20,232, but IDs are not contiguous. This analysis starts from the 16,397-document development corpus—the main analysis split used to construct and rank parent candidates. The separately reserved holdout split is not used in this ranking. Automatic reference matching identifies parents for 2,102 children, leaving 14,295 unresolved children for candidate ranking. Candidate 1 exists for 14,291 children and Candidate 2 for 14,287. Each chart's n is the number of those candidate rows with a non-missing score in that channel, so it can be smaller again.
