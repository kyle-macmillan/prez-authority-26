Qwen topical coverage and similarity

Qwen reranks the RRF top-ten candidate set. Similarity values are cosine similarities; higher values indicate greater similarity. Operative similarity is the bidirectional best-segment aggregate.

How to read this report

Document embedding similarity compares each directive as a whole, using its overall semantic representation. It captures broad subject-matter and meaning overlap.

Operative embedding similarity compares the directive’s operative provisions—the passages that contain commands, duties, authorities, or actions—rather than treating the full document as one undifferentiated text.

Full-operative Qwen scores every operative provision in the later (child) directive against every operative provision in the earlier (parent) candidate. The displayed score aggregates the strongest matches in both directions, so it asks whether the two directives have similar operative coverage overall.

More specifically, “strongest matches” means: (1) for each child provision, keep only its highest-scoring parent provision; (2) average those best child-to-parent scores; (3) for each parent provision, keep only its highest-scoring child provision; (4) average those best parent-to-child scores; and (5) average the two directional results.

Matched-pairs Qwen uses only the provision pairs identified by the embedding-based alignment step. This focuses Qwen on the passages that the retrieval stage considered most corresponding, instead of scoring every possible provision pair.

Qwen score distributions show the model’s yes-probability for the selected child–parent matches. Higher values indicate stronger model support for the match; lower values indicate weaker support.

A non-matching example is a topic directive whose top-ranked Qwen parent belongs outside that topic. For example, an IEEPA child may receive a parent that does not mention IEEPA. These are review examples—not necessarily errors—and help reveal whether the model is matching broader function or operative language rather than the topic label itself.

The distribution tables and histograms summarize the embedding scores for the selected top-1 rows in each cohort and Qwen representation; they are not distributions of every candidate pair.

Dataset composition

  • Directive universe: the report uses the presidential-directive corpus represented in the document and operative-segment files.
  • Candidate inputs: each later directive contributes its RRF-selected top-ten earlier candidates. The report contains 69,935 candidate rows across 7,011 later directives.
  • Overall cohort: the overall tables summarize one top-ranked parent per later directive, separately for full-operative and matched-pairs Qwen.
  • IEEPA cohort: directives whose extracted vesting clause mentions “IEEPA” or “International Emergency Economic Powers Act.”
  • National Emergencies Act cohort: directives whose extracted vesting clause mentions “National Emergencies Act.”
  • Topic status: within each topic, the report distinguishes directives with an automatic parent, directives scored by Qwen, and directives analyzed without Qwen.
